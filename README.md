# Tesla Model S (2021+ 改款) · 五端全場景智能座艙 HMI 實時系統

> **概念設計，非官方產品 (Concept Design, Non-Official Product)** · 對標車型：**Tesla Model S (2021+ Palladium 改款)**

本專案為可直接於桌面瀏覽器實時運行的量產級質感座艙 HMI 演示系統，採用 **Three.js (WebGL2)** 為 3D 渲染核心，配備 **WebGL2 4x MSAA 多重採樣 + SMAA 抗鋸齒雙重管線、2048×2048 高解析度陰影、程序化柏油路面法線/粗糙度貼圖、磨損車道標線、路燈體積光暈與夜間濕潤路面反射**，並透過中央車輛狀態機實現五端毫秒級同步。

## 一、五端分工與補齊功能

1. **iOS 手機 App（3D 鈦金屬邊框模型，可拿起放大至全屏）**：
   - 遵循 iOS 實機規範（安全區、狀態欄、靈動島、Home 指示條、原生轉場），手機內車燈曝光柔和不刺眼。
   - 完整涵蓋：**車輛定位地圖、一鍵發送目的地到車、行程能耗記錄、08:15 預約出發、數位鑰匙管理、安全與哨兵設置、OTA 軟件更新、服務中心預約**。
2. **17 吋中控橫屏（比例 2200:1300，支援向駕駛側傾斜）**：
   - 左側為 ADAS 3D 實時感知視圖、P/R/N/D 換擋軌、紧湊「車門／前備箱／尾箱／充電口」圖標按鈕列與獨立音樂卡（上下分離絕不重疊）。
   - 右側為 100% 離線多層級向量導航地圖，支援 **目的地搜尋與三路線選擇（最快 / 節能 / 景觀）**。
   - 底部 Dock 整合：**應用列表、完整 7 大設置分頁（顯示、燈光、鎖車、輔助駕駛、安全、日程、服務）、充電管理頁、360° 環視相機、藍牙電話與通訊錄、自然語音控制**。
3. **方向盤後 8:3 橫條儀錶盤**：
   - 嚴格執行分工：儀錶盤只顯示駕駛必要信息（等寬車速、擋位、**胎壓/車門/低電量報警**、**轉向燈與雙閃指示**、**限速與輔助駕駛狀態**、**實時 Wh/km 能耗曲線**），導航地圖與所有控制均置於中控屏。
4. **擋風玻璃無框透明 AR-HUD（概念設計）**：
   - 直接作為透明光學層疊加於擋風玻璃外的真實 3D 道路上（非獨立方框），顯示 **車道偏離光學提示、動態變色跟車距離色帶（綠/珀/紅）、3D 貼地導航轉向箭頭**。
5. **副駕娛樂屏（概念設計）**：
   - 包含原創虛構歌單黑膠與單色細線頻譜、**8 部真正可播放的多場景程序化動態短片**（灣岸星軌、極光冰原、阿爾卑斯雪山、風洞流線等）、以及 3D 街機競速；音量控件與歌名完整顯示並與主屏 100% 聯動。

## 二、快速運行說明 (How to Run)

```bash
cd "/Users/usagi/Documents/ Tesla HMI Gemini4"
python3 -m http.server 8080
```
接著在瀏覽器開啟 **[http://localhost:8080/?v=16](http://localhost:8080/?v=16)**。
